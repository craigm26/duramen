budgets) produced a passing implementation in under two minutes. Both clarify items came from
how tilth wrote the brief. The renderer showed an expected object in the order the author
typed it, and the builder read that order as contradicting the canonical JSON edge; and the
operations table never said that inputs are required. The checker could see neither: C-1's
example was correct, and no example sent a request without `value`. Only a reader could. The renderer now shows example values sorted
(objects typed in requirement prose, such as REQ-FL-002's `constants`, still appear as typed,
so since brief-t3 the brief says that objects list their members in no particular order).
