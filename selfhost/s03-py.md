## What this run taught
A Python build from a brief that leans on ECMAScript in places (`JSON.stringify`, `\s`, member
order) still came out complete and a fixed point; s03 wrote its own `jsutil.py` to match. The
fixed point needed the comparison the specification itself uses: as JSON values, not as text,
since member order means nothing in this protocol. The one `clarify` came from the previous
round's fix: a sentence written to pin one behavior ("not read further") also said something
about another, and duramen did not do it.
