## What this run taught
Its note on numbers was the one that led somewhere: Python writes a number too large for
binary64 as `Infinity`, which is not JSON. Tried on duramen and s06, the same number turned out
to be written as `null`, silently, into the suite's checks and into request lines, and the spec
had never said what such a number is. Its other choices were confirmations (18 already pinned)
and the deliberate gaps.
